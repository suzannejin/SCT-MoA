# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Research pipeline for evaluating 17 measures of association (correlation/distance metrics) for single-cell transcriptomics (scRNA-seq) data. Analyzes 211 datasets (162 GEO, 10 10X Genomics, 39 mousebrain.org) to assess functional coherence, network overlap, cell clustering, reproducibility, and disease gene prediction.

## Running the Pipeline

The pipeline uses **Nextflow DSL2** with containerized execution (`suzannejin/dismay:v3.5`).

```bash
# Run with Docker
nextflow run main.nf -profile docker

# Run with Singularity (e.g., on HPC)
nextflow run main.nf -profile singularity

# Run on CRG cluster
nextflow run main.nf -profile singularity,crg

# Run test configuration
nextflow run main.nf -profile test,docker

# Resume a failed/interrupted run
nextflow run main.nf -profile docker -resume
```

There are no lint or test commands. The project is research code without a formal test suite.

## Architecture

### Pipeline (Nextflow)

`main.nf` orchestrates three analysis stages via modules in `modules/`:

1. **Coexpression** (`modules/coexpr.nf`): Generates coexpression matrices using `dismay` R package, then filters by gene expression prevalence
2. **Functional coherence** (`modules/evaluation.nf` → `RUN_EGAD`): Computes AUROC for GO and Reactome annotations using `EGAD` package
3. **Network overlap** (`modules/network.nf` + `modules/evaluation.nf`): Rewires reference biological networks 1000x as null models, then calculates overlap with coexpression networks

Pipeline scripts live in `bin/` and are invoked by Nextflow processes. `bin/functions.R` provides shared utilities (gene mapping, species detection, annotation loading).

### Standalone R analysis (`R/`)

Scripts in `R/` are **not** part of the Nextflow pipeline. They handle:
- Data preprocessing (`R/geo/`, `R/10xgenomics.com/`, `R/mousebrain.org/`)
- Additional analyses: clustering (`R/clustering/`), reproducibility (`R/reproducibility/`), disease genes (`R/disease/`)
- Figure generation and supplementary tables (`R/tables/`)

`R/functions.R` and `R/theme.R` provide shared utilities and ggplot2 theme for standalone scripts.

### Key parameters (`nextflow.config`)

- **Input**: `data/one-per-publication/*.txt.gz` (filtered expression matrices)
- **Methods**: Currently set to 5 SJIN variants (`rhoSJIN`, `pearsonSJIN`, `spearmanSJIN`, `zi_kendallSJIN`, `partialcorSJIN`); CLR variants are commented out
- **Reference networks**: HIPPIE (PPI), OmniPath (signaling), Reactome (metabolic), STRING (text-mining) in `data/networks/`
- **Output**: `results/` (gitignored)
- **Eval filtering**: `['main']` by default; can be expanded to `[50,60,70,80,90,95,'main']`

### Data layout

- `data/geo/raw/` → raw GEO files; `data/geo/processed/` → standardized; `data/geo/filtered/` → gene-filtered
- `data/one-per-publication/` → one randomly sampled dataset per publication (main analysis input)
- `data/networks/` → reference biological networks with species-specific files
- `data/networks/rewired/` → gitignored, generated by pipeline

## Key R Dependencies

`dismay` (association metrics), `propr`/`propr_sjin` (proportionality), `EGAD` (functional coherence), `igraph` (networks), `org.Hs.eg.db`/`org.Mm.eg.db` (gene annotations). All pre-installed in the Docker container.

## Environment Notes

`nextflow.config` sets `R_PROFILE_USER` and `R_ENVIRON_USER` to isolate container R from host libraries. The container runs as the invoking user via Docker `--user` flag.
